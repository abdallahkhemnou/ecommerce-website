# 🛒 E-Commerce Website

A full-stack e-commerce web application featuring product browsing, cart management, secure checkout, and order history — built as a practical project to strengthen full-stack development skills.

## ✨ Features

- Browse products with detailed views
- Add/remove items from cart
- Secure checkout flow
- User authentication (sign up / sign in)
- Order history and confirmation

## 🛠️ Tech Stack

**Frontend:** React, Tailwind CSS
**Backend:** Node.js, Express
**Database:** PostgreSQL
